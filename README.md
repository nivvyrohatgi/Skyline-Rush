
# Paper Plane: Skyline Rush

An original Flappy Bird-inspired game about flying a paper plane through a city skyline.

## Controls
- Space or Up Arrow: flap
- R: restart
- Mouse click on the game: flap

## Features
- Keyboard-controlled movement
- Randomly spaced city obstacles
- Collision detection and game-over state
- Score counter
- Restart button
- Best score saved in browser storage when available

## How to Play
Open `index.html` in a modern desktop browser and click Start Flight.

## Technologies
HTML, CSS, JavaScript and HTML Canvas.
